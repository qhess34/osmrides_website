OSMrides

Des simulations d'exploitation, vues du dessus, construites sur le terrain réel tel que le décrit OpenStreetMap. Vous ne pilotez pas un véhicule : vous tenez le poste de commande.

Les jeux Principes Contribuer

Le projet

OSMrides part d'un constat simple : OpenStreetMap décrit déjà, au mètre près, le tracé d'une montagne russe, sa gare, sa file d'attente, ou les remontées et les pistes d'une station. Le projet en fait des simulateurs où l'on exploite ces installations comme le ferait une équipe sur place : départs, sécurité, file, garage, pannes, météo.

Tout fonctionne dans le navigateur, sur ordinateur comme sur téléphone, sans compte ni installation. Le jeu peut ensuite s'installer comme une application et fonctionner hors ligne.

Les jeux

Parc Astérix

Chef d'attraction sur Tonnerre 2 Zeus, la Trace du Hourra, OzIris et Goudurix : pupitre, trains, quai, file et garage.

Jouer

Stations de ski

Exploitation des remontées mécaniques d'un domaine skiable, sur leur tracé réel. Premier domaine étudié : Vars Les Claux.

Bientôt

Principes

OpenStreetMap est la référence

Tracés, gares, files, bâtiments et chemins viennent d'OpenStreetMap. Quand la carte change, le jeu suit.

Commande par zones

Comme au vrai pupitre, on commande des zones (gare, lift, freins, garage), jamais un train à la main. Les sécurités s'ouvrent et se verrouillent au bouton.

Estimations signalées

Ce qu'OpenStreetMap ne dit pas (hauteurs, longueur des wagons, couleurs) est estimé, et toujours présenté comme tel, jamais comme mesuré.

Rendu réaliste

Vue aérienne crédible, couleurs sourdes, rien d'enfantin : on regarde une installation, pas un dessin animé.

Contribuer

Améliorer la carte

La meilleure façon d'améliorer le jeu est d'améliorer OpenStreetMap : tracé d'une voie, gare, chemin de file, revêtement d'une allée, matériau d'une barrière. Ces informations profitent à tous les utilisateurs de la carte, et le jeu les reprend.

L'éditeur local

Ce qui relève du jeu et non de la carte (barrières de file, salle de contrôle, zone d'attente du quai, trains) se règle dans un éditeur qui s'ouvre sur son propre ordinateur et montre le rendu exact du jeu. Les réglages qui ont un équivalent dans OpenStreetMap peuvent y être renvoyés à la demande, jamais automatiquement. Mode d'emploi : éditeur OSMrides.

Le code

Le code est ouvert : moteur, parcs, stations de ski, ce site. Remarques et erreurs constatées : ouvrir une issue dans le dépôt concerné.
