# osmrides_website

Partie d'OSMrides : le site d'accueil d'OSMrides : présentation du projet, liens vers les jeux (parcs, stations), concepts (OSM comme référence, commande par zones, éditeur), comment contribuer (éditer OSM, éditeur local).

Jeu de fan non officiel, données © contributeurs OpenStreetMap (ODbL).

Site publié : https://qhess34.github.io/osmrides_website/ (GitHub Pages, workflow `.github/workflows/pages.yml`, à chaque poussée sur `main`). Une seule page, `index.html` + `site.css`, aucune dépendance. Le logo, les icônes et l'image du Parc Astérix sont copiés d'`osmrides`.
